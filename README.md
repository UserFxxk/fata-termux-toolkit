# Fata Toolkit V2 🚀

Toolkit sederhana berbasis Python untuk membantu produktivitas pengguna Termux.

## ✨ Fitur
- **Update System:** Mempercepat proses pembaruan package.
- **Auto Installer:** Menginstall Git, Python, dan Neofetch secara otomatis.
- **Networking:** Cek koneksi internet dan IP publik dengan cepat.
- **Quick Notes:** Menyimpan catatan penting langsung dari terminal.
- **Auto Clean:** Membersihkan cache sisa instalasi.

## 🚀 Cara Instalasi
Pastikan kamu sudah menginstall Python dan library colorama:
```bash
pkg install python
pip install colorama
git clone [https://github.com/steejoss306-commits/termux-toolkit](https://github.com/steejoss306-commits/termux-toolkit)
cd termux-toolkit
python toolkit.py
